## 1. 产品概述

### 1.1 产品愿景

构建一个面向企业人力资源、招采、合规管理人员的**一站式政策监控看板**，实时汇聚中央到地方层面的人力资源、税务、社保、合规相关政策法规和动态信息，帮助企业在灵活用工、劳务派遣、薪税合规、社保缴纳等核心业务场景中，快速感知政策变化、识别合规风险、辅助经营决策。

### 1.2 产品定位

本产品定位为**内部运营工具**，面向企业总部招采、人力资源、法务合规等部门，提供以下核心价值：

- **政策全景**：收录 2007–2026 年间 46 条核心政策法规，覆盖 6 大品类，形成完整的政策演进图谱。
- **风险监控**：以四色风险地图直观呈现各省份合规态势，支持按省份快速筛选关联政策。
- **多维检索**：时间轴、表格、看板三种视图自由切换，层级×品类×省份三维交叉筛选。
- **每日动态**：模拟 12 条监控动态（新增、即将生效、合规预警、重要动态），按时间倒序呈现。

### 1.3 参考原型

本看板的产品设计和模块布局参考了《灵活用工·外包·派遣·薪税·社保 政策图谱（2007–2026）》HTML 交互文档，延续了以下设计基因：渐变深色头部、指标卡片组、时代导航/品类筛选控件、卡片式政策展示、模态详情弹窗。

## 2. 目标用户与用户画像

### 2.1 核心用户

| 角色 | 职责 | 核心诉求 |
|------|------|----------|
| 总部招采/采购管理人员 | 供应商履约监控、外包服务管理 | 掌握劳务派遣比例合规、外包政策动向，降低用工合规风险 |
| 人力资源管理人员 | 灵活用工、社保缴纳、劳动关系管理 | 跟踪灵活就业政策、社保改革、职业伤害试点进展 |
| 法务/合规管理人员 | 企业合规审查、风险预警 | 关注薪税合规（增值税法、涉税信息报送）、劳务派遣比例红线 |
| 财务/薪税管理人员 | 薪税处理、发票管理 | 跟踪增值税法施行、个税核定征收变化、平台涉税信息报送 |

### 2.2 用户画像

**典型用户**：企业总部运营岗，无编程开发经验，日常使用钉钉、浏览器端办公系统、Excel/WPS 等工具。偏好简洁清爽的 Notion 风格 UI，对数据密度和排序方向敏感，希望所有列表默认按时间倒序（最新在前）排列。

### 2.3 使用场景

| 场景 | 描述 |
|------|------|
| 每日晨检 | 打开看板查看"今日监控动态"，快速浏览本周新增政策、即将生效法规、合规预警 |
| 合规排查 | 通过风险地图发现某省份标记为"高风险"，点击筛选查看该省全部关联政策 |
| 政策研究 | 切换至时间轴视图，按年份浏览政策演进脉络，点击卡片查看政策全文摘要 |
| 数据导出 | 切换至表格视图，通过三维筛选缩小范围，浏览结构化政策列表 |

### 3.3 监控看板视图（Dashboard View）

#### 3.3.1 今日监控动态（Alert Feed）

**功能描述**：全宽卡片，展示最新政策监控动态，按时间倒序排列（最新在前）。

**布局**：全宽占满，卡片内最大高度 420px，超出可滚动。

**每条动态包含**：

| 字段 | 说明 |
|------|------|
| 类型指示点 | 左侧 8px 圆点，按类型着色：本周新增（绿）、即将生效（黄）、合规预警（红）、重要动态（蓝） |
| 标题 | 13px 粗体，单行 |
| 元信息行 | 品类标签（带色）+ 类型文本 + 日期 + 涉及省份 |
| 摘要 | 11px，两行以内 |

**动态类型与数量**：

| 类型 | 标识色 | 数量 |
|------|--------|------|
| 本周新增（new） | #10B981 | 3 条 |
| 即将生效（upcoming） | #F59E0B | 4 条 |
| 合规预警（warning） | #EF4444 | 2 条 |
| 重要动态（info） | #3B82F6 | 3 条 |

**交互**：点击任意动态条目，打开详情弹窗（Modal），展示完整信息。

#### 3.3.2 地方政策风险地图（Province Risk Map）

**功能描述**：SVG 中国省份地图，以四色风险等级填充各省，叠加政策数量徽标，支持点击省份筛选关联政策。

**地图建模**：

- 34 个省级行政区（含港澳台），每省使用 12–28 个经纬度坐标点定义多边形边界。
- 坐标变换公式：`x = (lon - 73) * 10`，`y = (54 - lat) * 11.5`。
- SVG viewBox：`-20 -10 650 540`。
- 台湾、海南在右下角以独立缩略框呈现（南海诸岛 inset）。

**风险等级体系**：

| 等级 | 填充色 | 描边色 | 文字色 | 判定依据 |
|------|--------|--------|--------|----------|
| 高风险 | #FEE2E2 | #EF4444 | #991B1B | 政策密集且存在明确合规风险（如广东：6条政策 + 薪税合规/劳务派遣/灵活就业立法多重风险） |
| 中风险 | #FEF3C7 | #F59E0B | #92400E | 有 2 条以上政策且涉及需关注领域（如天津/海南/江西/重庆的薪税代征、北京/上海/江苏的职业伤害试点） |
| 低风险 | #D1FAE5 | #10B981 | #065F46 | 有 1 条政策，监管态势平稳（如山东、浙江、湖北、四川等） |
| 暂无数据 | #F1F5F9 | #CBD5E1 | #64748B | 暂无地方性政策收录（如新疆、西藏、青海、河南、福建、云南、广西等） |

**风险分类详情**：

| 风险等级 | 省份 | 风险说明 |
|----------|------|----------|
| 高风险 | 广东 | 6条政策：灵活就业立法+深圳权益保障决定+劳务派遣合规+职业伤害试点+薪税代征 |
| 中风险 | 天津、海南、江西、重庆 | 薪税委托代征+个税核定征收政策变动，需关注核定征收范围收紧 |
| 中风险 | 北京、上海、江苏 | 职业伤害保障试点+劳务派遣过渡方案，试点政策持续演进中 |
| 低风险 | 山东、宁夏、内蒙古、湖北、浙江、湖南、四川、辽宁 | 各有 1 条政策，监管态势平稳 |
| 低风险 | 海南 | 职业伤害试点+薪税代征双重覆盖但政策体量较小 |
| 暂无数据 | 新疆、西藏、青海、甘肃、陕西、山西、河北、河南、安徽、福建、贵州、云南、广西、吉林、黑龙江、香港、澳门、台湾 | 暂无地方性政策收录 |

**地图元素**：

- 省份多边形：填充风险色，描边 1.8px（无数据省份 0.8px）。
- 省份简称标签：8.5px 粗体，风险区显示深色文字，无数据区显示灰色。
- 数量徽标：有政策的省份在简称上方显示圆形徽标（半径 = 6 + min(count, 8) × 1.8），填充风险描边色，白色数字。
- 选中态：描边加粗至 3px，颜色 #1E40AF。
- 悬停态：透明度降低至 0.8，描边加粗至 2.5px。

**图例**：底部横向排列，包含四色风险色块（18×12px 圆角矩形）+ 数量徽标示例。

**交互**：
- 点击省份 → 激活省份筛选，联动时间轴和表格视图。
- 再次点击已选省份 → 取消筛选，恢复"全部省份"。
- 头部标签动态更新："点击省份筛选" ↔ "已选：广东"。

### 3.5 表格视图（Table View）

**功能描述**：全量政策以结构化表格呈现，默认按日期倒序排列（最新在前）。

**表格列定义**：

| 列名 | 字段 | 说明 |
|------|------|------|
| 日期 | date | 蓝灰色粗体，不换行 |
| 层级 | level | 徽章样式 |
| 品类 | category | 徽章样式 |

**表格样式**：
- 表头：灰底 #F1F5F9，sticky 固定顶部，2px 底部描边。

- 单元格：8px 内边距，底部 1px 细线分隔。

**交互**：
- 受全局筛选联动：不匹配的行隐藏。
- 行内携带 `data-orig-idx` 属性，确保排序后筛选索引正确。

**监控动态详情内容**：

| 字段 | 说明 |
|------|------|
| 标题 | 18px 粗体 |
| 元信息标签组 | 品类（带色）+ 日期 + 涉及省份 |
| 描述正文 | 13px，行高 1.8 |

**关闭方式**：右上角关闭按钮、点击遮罩、按 Esc 键。

### 3.7 三维筛选系统

**功能描述**：层级 × 品类 × 省份三维交叉筛选，联动全部视图。

**筛选逻辑**：

```
显示条件 = (层级匹配 OR 层级=全部)
         AND (品类匹配 OR 品类=全部)
         AND (省份匹配 OR 省份=全部 OR 政策层级=中央)
```

**关键规则**：
- 中央层级政策在任何省份筛选下均保持显示（因中央政策全国适用）。
- 地方层级政策仅在省份匹配或"全部省份"时显示。
- 筛选状态由全局变量 `curLv`、`curCat`、`curProv` 维护。

**联动范围**：
- 时间轴视图：隐藏不匹配的政策卡片，若某年份下无可见卡片则隐藏该年份。
- 表格视图：隐藏不匹配的表格行。
- 地图：省份选中态高亮。

## 7. 技术架构

### 7.1 前端架构

```
单文件 HTML
├── <style>        全部 CSS 样式（含响应式）
├── <body>         静态 HTML 结构（Header / Controls / Dashboard / Timeline / Table / Modal / Footer）
└── <script>       全部 JavaScript 逻辑
    ├── 数据层      policies[] / alerts[] / provMap[]
    ├── 渲染层      renderAlerts() / renderMap() / renderCatSummary() / renderTimeline() / renderTable()
    ├── 交互层      switchView() / filterLevel() / filterCat() / filterByProvince() / applyFilters()
    ├── 弹窗层      showPolicyDetail() / showAlertDetail() / closeModal()
    └── 工具函数    lonToX() / latToY() / riskColors{}
```

### 7.2 SVG 地图技术

| 技术点 | 实现方案 |
|--------|----------|
| 省份形状 | SVG `<polygon>` 元素，每省 12–28 个经纬度坐标点 |
| 坐标变换 | `x = (lon - 73) * 10`，`y = (54 - lat) * 11.5` |
| 质心计算 | 多边形顶点坐标平均值，用于放置简称标签和数量徽标 |
| 风险着色 | 按 risk 字段查 riskColors 映射表，动态设置 fill 和 stroke |
| 数量徽标 | SVG `<circle>` 叠加在省份上方，半径与政策数量正相关 |
| 缩略框 | 台湾、海南在 viewBox 右下角以独立缩放比例渲染 |
| 阴影效果 | SVG `<filter>` + `<feDropShadow>` 为数量徽标添加投影 |

### 7.3 状态管理

全局状态由三个变量维护：

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| curLv | string | "all" | 当前层级筛选 |
| curCat | string | "all" | 当前品类筛选 |
| curProv | string | "all" | 当前省份筛选 |

每次筛选操作更新对应变量后调用 `applyFilters()`，遍历所有政策卡片和表格行执行显隐判断。

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 政策数据更新不及时 | 看板信息滞后，用户无法感知最新变化 | Phase 3 对接自动化数据源；当前阶段定期人工更新 |
| 省份地图形状精度有限 | 部分省份轮廓与真实边界存在偏差 | 已采用 12–28 坐标点建模，后续可引入 GeoJSON 数据提升精度 |
| 风险等级判定主观性 | 不同用户对"高/中/低"风险理解不同 | 在 provMap 数据中显式定义 risk 字段，提供判定依据说明；后续支持用户自定义 |
| 单文件架构扩展性有限 | 数据量增长后 HTML 文件过大 | Phase 3 迁移至前后端分离架构，数据通过 API 加载 |
| 无外部 CDN 依赖限制 | 无法引入图表库、地图库等增强功能 | 当前阶段使用 vanilla JS + 内联 SVG；Phase 4 迁移至完整 Web 应用后解除限制 |
